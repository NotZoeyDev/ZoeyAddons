# Zoey's Addons

Unity editor tools for VRChat avatar projects.

## Install

Open <https://notzoeydev.github.io/ZoeyAddons/> and press **Add to VCC / ALCOM**.

Or, in VCC or ALCOM, go to **Settings → Packages → Add Repository** and paste:

```
https://notzoeydev.github.io/ZoeyAddons/index.json
```

## Tools

| Tool | What it does |
|---|---|
| **Unused Asset Finder** | Finds materials and textures in your project that aren't used in the scenes you pick. Open it from **Tools → Unused Asset Finder**. |
